Entegrasyon

            
Bu uygulamanın API’si veya doğrudan Cloudflare ile tünele subdomain açma

          

        


        

          
          
          
          
        


        

          
Bu iş ne işe yarar?

          
İnternetten biri admin.example.com yazar. İstek Cloudflare tüneline gelir, tünel de senin bilgisayarındaki programa (ör. Express, port 3001) götürür. Program kapalıysa site açılmaz. Tünel kapalıysa da açılmaz.

          

            

              
Subdomain nedir?

              
admin.example.com gibi başında bir isim olan adres. Aynı domainin ayrı bir kapısı. admin başka porta, api başka porta gidebilir.

            

            

              
Kök domain nedir?

              
example.com — başında isim yok, ana site. Bu uygulamada subdomain kutusunu boş bırakırsan kök domain açılır.

            

          

          
Önce bunları yap (sırayla)

          
1
Canlı tünel seç
Pencerenin en üstündeki kutudan tüneli seç. Sadece healthy (yeşil / canlı) olanlar seçilir. Seçmezsen hostname yazılmaz.

          
2
API sunucusunu aç
Sol menü → API → Yönet → Başlat. Yeşil kalp = API açık, kırmızı kalp = kapalı. Adres genelde http://127.0.0.1:7000

          
3
API anahtarı üret
Sol menü → Anahtarlar → etiket yaz → Anahtar Oluştur. Çıkan czt_... değerini kopyala. Bir daha gösterilmez.

          
4
Domain sende olsun
example.com Cloudflare hesabında olmalı. Domainler sayfasında görünüyorsa tamam. Görünmüyorsa nameserver’lar Cloudflare’de değil demektir.

          
Bundan sonra ya bu uygulamanın REST API’sini kullanırsın (kolay) ya da Express örneğini çalıştırırsın. Cloudflare’i elle de yazabilirsin; o daha ileri seviye.

        


        

          
Kod ile subdomain / kök domain

          
Aşağıdaki dosya bu uygulamanın API’sine bağlanır. Önce “Nasıl çalışır”daki 1–4. adımları bitir. KEY yerine kopyaladığın anahtarı koy.

          
1
Subdomain açmak
openSubdomain('admin', 'example.com', 3001) → internette admin.example.com, senin PC’de http://127.0.0.1:3001. 3001’de bir şey dinlemelisin.

          
2
Kök domain açmak
İlk parametreyi boş bırak: openSubdomain('', 'example.com', 8080) → example.com ana site olur, 8080 portuna gider. Panelden de subdomain kutusunu boş bırakmak aynı şey.

          
3
Silmek
deleteSubdomain('admin.example.com') hem tünel kuralını hem DNS kaydını siler. Kök için deleteSubdomain('example.com').

          
4
Çalıştır
Dosyayı czt-subdomain.js kaydet. PowerShell: $env:CZT_API_KEY="czt_xxx"; node czt-subdomain.js

          
Hazır olunca kodu kopyala:

          

            
czt-subdomain.js

            
const CZT = process.env.CZT_URL || 'http://127.0.0.1:7000';
const KEY = process.env.CZT_API_KEY; // Anahtarlar sayfasından

async function czt(method, path, body) {
  const res = await fetch(CZT + path, {
    method,
    headers: {
      'X-API-Key': KEY,
      'Content-Type': 'application/json'
    },
    body: body ? JSON.stringify(body) : undefined
  });
  const json = await res.json();
  if (!res.ok || json.success === false) {
    throw new Error(json.error || res.statusText);
  }
  return json.result;
}

// Domain seçimi: zone example.com, subdomain admin
async function openSubdomain(sub, domain, port) {
  const hostname = sub ? sub + '.' + domain : domain;
  return czt('POST', '/api/hostnames', {
    hostname,
    service: 'http://127.0.0.1:' + port
  });
}

async function deleteSubdomain(hostname) {
  return czt('DELETE', '/api/hostnames/' + encodeURIComponent(hostname));
}

openSubdomain('admin', 'example.com', 3001)
  .then((r) => console.log('opened', r))
  .catch(console.error);

// deleteSubdomain('admin.example.com').then(() => console.log('deleted'));

          

        


        

          
Express ile admin.example.com

          
Küçük bir Node sitesi ayağa kalkar, tünele admin.example.com yazar, Ctrl+C deyince hem siteyi hem adresi siler. Önce “Nasıl çalışır” 1–4 bitti varsayılır.

          
1
Node.js kur
https://nodejs.org aç → LTS (önerilen) indir → kurulumda Next / Install. Bitince PowerShell aç, node -v yaz. v20 veya v22 benzeri bir sayı gelmeli. npm -v da sayı vermeli.

          
2
Klasör aç
İstediğin yerde: mkdir admin-site   sonra   cd admin-site   sonra   npm init -y   sonra   npm i express

          
3
admin.js yapıştır
Aşağıdaki kodu kopyala, klasöre admin.js diye kaydet. czt_PASTE_KEY yerine 3. adımda kopyaladığın anahtarı koy. DOMAIN kendi domainin (example.com). SUB admin ise adres admin.example.com olur. Kök domain için SUB değerini boş bırak: const SUB = ''.

          
4
Çalıştır
node admin.js  —  “tunnel hostname admin.example.com” yazmalı. Yazmazsa API kapalıdır veya anahtar yanlıştır.

          
5
Tarayıcıda aç
https://admin.example.com  (kök yaptıysan https://example.com). İlk sefer 1 dakika DNS bekleyebilir.

          
6
Kapat / sil
Terminalde Ctrl+C. Express durur ve uygulama hostname’i siler. Elle silmek istersen Tüneli Yönet sayfasından Sil.

          
Hazır olunca kodu kopyala:

          

            
admin.js

            
const express = require('express');

const CZT = process.env.CZT_URL || 'http://127.0.0.1:7000';
const KEY = process.env.CZT_API_KEY || 'czt_PASTE_KEY';
const DOMAIN = process.env.DOMAIN || 'example.com';
const SUB = process.env.SUB || 'admin';
const PORT = Number(process.env.PORT || 3001);
const HOSTNAME = SUB ? SUB + '.' + DOMAIN : DOMAIN;

async function czt(method, path, body) {
  const res = await fetch(CZT + path, {
    method,
    headers: { 'X-API-Key': KEY, 'Content-Type': 'application/json' },
    body: body ? JSON.stringify(body) : undefined
  });
  const json = await res.json();
  if (!res.ok || json.success === false) throw new Error(json.error || res.statusText);
  return json.result;
}

async function openHost() {
  return czt('POST', '/api/hostnames', {
    hostname: HOSTNAME,
    service: 'http://127.0.0.1:' + PORT
  });
}

async function closeHost() {
  return czt('DELETE', '/api/hostnames/' + encodeURIComponent(HOSTNAME));
}

const app = express();
app.get('/', (_req, res) => {
  res.type('html').send('<h1>Admin</h1><p>' + HOSTNAME + '</p>');
});

async function main() {
  await openHost();
  console.log('tunnel hostname', HOSTNAME);
  const server = app.listen(PORT, '127.0.0.1', () => {
    console.log('http://127.0.0.1:' + PORT);
  });
  const shutdown = async () => {
    try { await closeHost(); console.log('hostname deleted'); } catch (e) { console.error(e); }
    server.close(() => process.exit(0));
  };
  process.on('SIGINT', shutdown);
  process.on('SIGTERM', shutdown);
}

main().catch((err) => { console.error(err); process.exit(1); });

          

        


        

          
Bu uygulama olmadan (ileri)

          
cloudflared zaten çalışıyorsa hostname’i doğrudan Cloudflare API ile yazabilirsin. Yeni başlıyorsan REST API veya Express sekmesini kullan. Bu yol token, account, tunnel ve zone ID ister.

          
1
Token izinleri
Account → Cloudflare Tunnel: Edit  ve  Zone → DNS: Edit. Yoksa 403 alırsın.

          
2
Ortam değişkenleri
CF_API_TOKEN, CF_ACCOUNT_ID, CF_TUNNEL_ID, CF_ZONE_ID (example.com’un zone id’si). HOSTNAME admin.example.com veya kök için example.com.

          
3
Aç / sil
node cf-direct.js açar. Silmek için dosyadaki deleteDirect() satırının yorumunu kaldır. Catch-all (http_status:404) ingress listesinin EN SONUNDA kalmalı, yoksa tünel bozulur.

          
Hazır olunca kodu kopyala:

          

            
cf-direct.js

            
const TOKEN = process.env.CF_API_TOKEN;
const ACCOUNT = process.env.CF_ACCOUNT_ID;
const TUNNEL = process.env.CF_TUNNEL_ID;
const ZONE = process.env.CF_ZONE_ID; // example.com zone id
const HOSTNAME = 'admin.example.com';
const SERVICE = 'http://127.0.0.1:3001';

async function cf(method, path, body) {
  const res = await fetch('https://api.cloudflare.com/client/v4' + path, {
    method,
    headers: { Authorization: 'Bearer ' + TOKEN, 'Content-Type': 'application/json' },
    body: body ? JSON.stringify(body) : undefined
  });
  return res.json();
}

async function openDirect() {
  const cur = await cf('GET', '/accounts/' + ACCOUNT + '/cfd_tunnel/' + TUNNEL + '/configurations');
  const ingress = (((cur.result || {}).config) || {}).ingress || [];
  const catchAll = ingress.filter((r) => !r.hostname);
  const rest = ingress.filter((r) => r.hostname && r.hostname !== HOSTNAME);
  const next = [{ hostname: HOSTNAME, service: SERVICE }].concat(rest, catchAll.length ? catchAll : [{ service: 'http_status:404' }]);
  await cf('PUT', '/accounts/' + ACCOUNT + '/cfd_tunnel/' + TUNNEL + '/configurations', {
    config: { ingress: next }
  });
  await cf('POST', '/zones/' + ZONE + '/dns_records', {
    type: 'CNAME',
    name: HOSTNAME,
    content: TUNNEL + '.cfargotunnel.com',
    proxied: true
  });
}

async function deleteDirect() {
  const cur = await cf('GET', '/accounts/' + ACCOUNT + '/cfd_tunnel/' + TUNNEL + '/configurations');
  const ingress = ((((cur.result || {}).config) || {}).ingress || []).filter((r) => r.hostname !== HOSTNAME);
  await cf('PUT', '/accounts/' + ACCOUNT + '/cfd_tunnel/' + TUNNEL + '/configurations', {
    config: { ingress: ingress.length ? ingress : [{ service: 'http_status:404' }] }
  });
  const dns = await cf('GET', '/zones/' + ZONE + '/dns_records?type=CNAME&name=' + encodeURIComponent(HOSTNAME));
  const rec = ((dns.result || [])[0]);
  if (rec) await cf('DELETE', '/zones/' + ZONE + '/dns_records/' + rec.id);
}

openDirect().then(() => console.log('opened')).catch(console.error);
// deleteDirect().then(() => console.log('deleted'));
